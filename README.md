# Project PocketGenesis

A research program on the mathematical foundations of protein pocket formation:
geometry, accessibility, stability, dynamics, cryptic pockets, and thermodynamic
certification — with exact certificates, a small trusted checker, and Lean 4
formalization of core results.

Status: active research. See `THEORY.md` (framework), `THEOREM_LEDGER.md`
(every result with proof status), `NOVELTY_AUDIT.md`, and
`SCIENTIFIC_LIMITATIONS.md`. Nothing in this repository is a claim about real
biological systems unless explicitly stated together with the modeling
assumptions it depends on.
